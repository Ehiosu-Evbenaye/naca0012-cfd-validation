# naca0012-cfd-validation
Steady‑state RANS CFD analysis of a NACA 0012 airfoil in STAR‑CCM+ at Re = 3×10⁶ using SST k‑ω turbulence model. Validated lift and drag coefficients (0°–12° AoA) against NASA Langley data (&lt;5% deviation for lift, &lt;8% for drag). Includes mesh independence study and uncertainty quantification.
